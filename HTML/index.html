O caminho dos dados

Marcas diferentes, uma única visão.

A proposta é ler cada equipamento do seu jeito, traduzir para um formato comum e mostrar tudo no painel. Hoje só o painel existe, com dados fictícios; as demais etapas dependem de validação técnica.

  1. Equipamentos de marcas diferentes (RS485, CAN, Modbus)
  2. Aquisição somente leitura: a validar com manuais e testes
  3. Normalização dos dados em um formato comum
  4. API e armazenamento: etapa futura, não implementada
  5. Painel centralizado: é o que este protótipo mostra
Fluxo planejado

Da medição à informação.

Esta é a arquitetura prevista para a solução. Cada integração será construída de acordo com as interfaces disponibilizadas pelo fabricante.

  1. Etapa 01

    Equipamentos

    Inversores e baterias disponibilizam as medições compatíveis.

  2. Etapa 02

    Interface ou gateway

    Um dispositivo compatível coleta e interpreta os dados acessíveis.

  3. Etapa 03

    Organização

    As informações são transmitidas e estruturadas pelo sistema.

  4. Etapa 04

    Plataforma

    Indicadores, históricos e alertas são apresentados em um só lugar.
